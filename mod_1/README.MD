# Подготовка к занятиям

Нужны Windows 10/11 и интернет.

1. Скачай проект. Если это ZIP-архив — распакуй его.
2. Закрой VS Code. В папке `mod_1` дважды нажми на **setup.cmd**.
3. Дождись сообщения **«Установка завершена!»**. VS Code откроется сам.
4. Открой файл нужного урока с расширением **.ipynb** в папке `les_…`.
5. Справа вверху нажми на название ядра или **Select Kernel** и выбери:
   **Select Another Kernel → Jupyter Kernels → maximum-venv**.
6. Запускай ячейки по порядку кнопкой **▶** слева от кода.

**Если установка завершилась с ошибкой:** отправь преподавателю файл `start/setup.log`.
