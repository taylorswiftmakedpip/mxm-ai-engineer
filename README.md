# Материалы курса

## Как скачать проект

1. Нажми **[Скачать проект](https://github.com/taylorswiftmakedpip/mxm-ai-engineer/archive/refs/heads/main.zip)**.
2. Найди скачанный ZIP-архив. Нажми на него правой кнопкой мыши → **Извлечь всё…** → **Извлечь**.
3. Открой распакованную папку `mxm-ai-engineer-main`, затем папку `mod_1`.

Дальше следуй **[инструкции по подготовке к занятиям](mod_1/README.MD)**.
